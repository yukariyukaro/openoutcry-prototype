PRODUCT BRIEF
一个入口，完成一次改进。
本文件合并 Agent 工作室与模拟交易场原型；详细产品规划仍保留在 Markdown 中。所有按钮仅操作浏览器内存中的演示数据。

          
01 · 准备 Agent
内置模板或本地接入 → 配置提示词 → 选择训练场模板。Skill 和协议放在辅助入口，不干扰日常操作。
02 · 进入训练场
AI 会话与模拟账户同屏。先看四个关键数字，需要时再切持仓、历史操作或盈亏。
03 · 回看与改进
从订单进入依据与规则详情，回放已保存事件。复制配置后再生成新运行，不覆盖原记录。
首版边界
  • 日频 A 股小股票池；不是真实证券交易。
  • 时点控制、T+1、费用与状态以明确规则执行。
  • 研究工具只检索和阅读，不代替参评 Agent 判断。
  • 自主、人工确认与追加指导分别留痕。

          
简化方式：三项主导航、双栏工作台、按需展开技术细节，不再让两份页面各自维护一套账户与会话。
